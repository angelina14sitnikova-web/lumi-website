# Четыре раздела Lumi

Главная сохраняет исходные логотип, приветственный экран, персонажа, фон, шрифты и нижний пейзаж. Новый блок содержит четыре карточки: «Приключения с Луми», «Академия Луми», «Энциклопедия Луми», «Мастерская Луми». Три будущих раздела имеют самостоятельные стартовые страницы без учебного контента.

## Добавление приключения

Данные хранятся в `site-sections/catalog-data.js`. Для новой игры добавьте запись в adventures: id, title, age, direction, description, cover, game, status; дополнительные поля — coverAlt, number и skills. Возрасты определены в ages, направления — в directions. Новое направление добавляется одной записью в directions; фильтры строятся автоматически.

Адрес каталога остаётся `crystal-world.html`. Старые якоря #age-3-4, #age-4-5, #age-5-6 и #age-6-7 работают. Выбор возраста записывается только в URL, не в игровые хранилища. При смене возраста выбираются «Все приключения». База данных и регистрация не нужны.

## Обложки

Четыре оригинальные иллюстрации созданы встроенным генератором изображений по приложенному пользователем листу референсов. Все итоговые WebP имеют размер 1200 × 800 пикселей. Они используются на карточках, а три соответствующие — также на страницах будущих разделов. Отдельные PNG персонажа не использовались.

| Файл | Сюжет и поза |
| --- | --- |
| assets/adventures.webp | Луми держит карту; тропинка объединяет сад, кристаллы, маяк и звёздную башню. |
| assets/academy.webp | Луми сидит за столом и перелистывает книгу в сказочной учебной комнате. |
| assets/encyclopedia.webp | Луми рассматривает раскрытую книгу с миниатюрным миром природы, космоса и океана. |
| assets/workshop.webp | Луми рисует цветок на мольберте в уютной художественной мастерской. |

Общие требования промптов: точно сохранить бежево-молочного щенка с круглыми голубыми глазами, висячими ушами, характерной чёлкой, коричневым носом, голубыми подушечками лап, полумесяцем и синей накидкой с круглой голубой застёжкой. Гладкая сказочная иллюстрация, мягкий объём, сиренево-голубые и розовые оттенки, золотые акценты; без зернистости, шума, пятен, надписей и интерфейса. Сцены создавались отдельно, с разными позами.
