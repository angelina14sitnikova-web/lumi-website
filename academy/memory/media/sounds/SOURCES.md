# Источники звуков «Долины хрустальных звуков»

Эти записи также подготовлены для звукового курса Академии Луми. Короткие фрагменты сведены в моно, приведены к комфортному уровню с плавными краями и перекодированы в MP3. Указанные лицензии распространяются и на эти фрагменты.
