# Данные Академии Луми

`courses.js` подключает предметы из отдельных файлов вида `speech-3-4.js`. В этих файлах задан порядок модулей и уроков. Программы 4–5 лет переиспользуют оформление соответствующих предметов, а их модули и уроки имеют собственные идентификаторы. Номер выводится по позиции в программе, а ссылки и прогресс используют постоянные идентификаторы. При перемещении или переименовании темы сохраняйте её ID. Используйте только латиницу в нижнем регистре, цифры и дефисы в идентификаторах.

В `lesson-content.js` добавляйте содержимое по ID урока, указанному в `courses.js`. До появления сцен урок открывается на странице подготовки. После добавления сцен доступно объяснение. Для завершения урока нужен непустой набор упражнений и правильные ответы на все из них.

## Поля содержимого урока

| Поле | Что указывать |
| --- | --- |
| `scenes` | Массив сцен в порядке показа |
| `scenes[].title`, `scenes[].text` | Заголовок и короткое объяснение |
| `scenes[].illustration.label` | Текстовое описание демонстрации для экранного диктора |
| `scenes[].illustration.image` | Необязательный путь к фоновой или самостоятельной иллюстрации относительно `academy/lesson.html` |
| `scenes[].illustration.layers` | Необязательный массив объектов на иллюстрации. У каждого слоя поля `image`, `x`, `y`, `width` в процентах для координат и ширины, а также необязательные `keyframes` и `duration` в миллисекундах |
| `scenes[].audio` | Необязательный путь к локальной аудиодорожке. Воспроизведение запускает посетитель |
| `practice` | Массив заданий от простых к более сложным |
| `practice[].kind` | Сейчас поддерживается `choice`, выбор одного ответа |
| `practice[].prompt`, `practice[].hint`, `practice[].success` | Инструкция, подсказка при ошибке и сообщение при успехе. Последнее поле необязательно |
| `practice[].choices` | Элементы с полями `id`, `label` и необязательным `image` |
| `practice[].correct` | ID правильного варианта |
| `challenge` | Необязательный набор более сложных задач в том же формате, открывается после основной практики |
| `parentMaterials` | Необязательный список материалов для взрослых с полями `title`, `text` и необязательной ссылкой `href` |

Если у подвижного слоя есть ключевые кадры, исходная позиция слоя должна оставаться понятной при отключённых анимациях. Прохождение хранится локально в `lumi.academy.completed.v1` после основной практики. Дополнительные задания не меняют этот прогресс и не начисляют повторную награду.

Чтобы добавить новый тип практики, добавьте проверку готовности и ответа в `practiceTypes` в `course-model.js` и обработчик выбора или ввода в `practiceViews` в `lesson.js`.

Для визуальных упражнений на сравнение используйте `format: 'comparison'` в уроке и `kind: 'comparison'` в его заданиях. Схемы сцен и заданий первого модуля находятся в `comparison-3-4.js`. Задания используют либо `rounds` с визуальными вариантами и индексом ответа, либо `options` и `pairs` с индексами пар. Прогресс записывается только после проверки всех упражнений. Фон и атлас игрушек находятся в `assets/comparison/`.
