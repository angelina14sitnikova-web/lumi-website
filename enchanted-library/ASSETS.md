# Графика приключения

В папке `assets/` — 44 PNG. Сгенерированы 22 новые иллюстрации; 6 ресурсов перенесены из утверждённого приключения «Звёздная башня»; 16 PNG построены из точной геометрии для игровых задач.

Новая растровая графика создана встроенным генератором изображений. Каждый объект создавался отдельно. Луми генерировался с опорой на утверждённый PNG из `star-tower/assets/lumi-thinking.png`. Сцены сказки используют единый образ путешественника и дракона. Изображения уменьшены до размеров, подходящих для игры, с сохранением альфа-канала.
