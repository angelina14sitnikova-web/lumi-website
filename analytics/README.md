# Яндекс Метрика Lumi — счётчик 114310945

## Установка и конфиденциальность

Все 21 HTML-страница подключает один `lumi-analytics.js`. Он загружает официальный SDK только после разрешения родителя, сохранённого в `lumi.analytics.consent.v1`. Никаких пикселей `noscript` и предварительных соединений с Яндексом нет. Можно закрыть уведомление, отказаться или отозвать согласие кнопкой «Родителям: настройки аналитики» внизу страницы. Без решения аналитика выключена.

Яндекс после согласия обрабатывает технические данные устройства, IP и cookie-идентификаторы; это не полностью анонимная статистика. Код Lumi не читает и не передаёт имена, голос или содержимое полей. Вызовы событий принимают только разрешённые технические идентификаторы; произвольные параметры не принимаются. Просмотры передаются без query, fragment, заголовка страницы и исходного referrer.

Настройки: `webvisor:false`, `clickmap:false`, `trackLinks:false`, `ecommerce:false`, `accurateTrackBounce:false`, `childIframe:false`, `trackHash:false`, `sendTitle:false`, `disableYtm:true`, `defer:true`. Просмотр отправляется явно один раз на документ. Дополнительно установлены официальные классы `ym-disable-submit`, `ym-disable-keys`, `ym-disable-clickmap`, `ym-disable-tracklink`, `ym-hide-content`. Динамические поля тоже защищены.

Повторное включение модуля не создаёт второй интерфейс или счётчик. Отзыв очищает очередь, закрывает шлюз событий и вызывает `destruct`. Уже начатые сетевые запросы могут завершиться; ранее отправленные данные не удаляются. Если SDK уже запрашивался, повторное разрешение начинает действовать со следующей страницы, чтобы не инициализировать счётчик повторно в том же документе. Отзыв распространяется на другие открытые вкладки через `storage`.

При недоступном localStorage решение действует только в текущем документе. При блокировке SDK игра продолжает работать. Очередь ограничена 50 техническими событиями, при ошибке загрузки очищается. События до согласия не восстанавливаются задним числом.

## Семь целей

| Идентификатор | Когда отправляется |
|---|---|
| age_3_4 | Нажатие выбора 3–4 года |
| age_4_5 | Нажатие выбора 4–5 лет |
| age_5_6 | Нажатие выбора 5–6 лет |
| age_6_7 | Нажатие выбора 6–7 лет |
| adventure_start | Начало или первое продолжение текущего прохождения |
| task_complete | Успешное окончание целого задания, не отдельного раунда |
| adventure_complete | Успешное окончание последнего задания; открытие старой награды не считается |

Параметры приключений: `adventure_id`, `age_group`; только для задания дополнительно `task_number` (целое 1–7). Возраст — категория контента, не возраст конкретного ребёнка. Для выбора возраста параметры не добавляются.

Идентификаторы: `crystal-trail` / `3-4`, `magic-garden` / `3-4`, `crystal-lighthouse` / `4-5`, `star-tower` / `5-6`, `enchanted-library` / `6-7`.

`lumi.analytics.runs.v1` в sessionStorage защищает начало, задания и завершение от повторов при двойном нажатии и обновлении страницы в рамках прохождения. Намеренное «Начать сначала» создаёт новый цикл событий. Начало и выбор возраста имеют дополнительную защиту 1200 мс. `lumi.analytics.pending.v1` переносит согласованные события на следующую страницу, если переход произошёл до загрузки SDK. Ключи игрового прогресса, наград и звука не меняются. После закрытия сессии браузера дедупликация начинается заново; это не межустройственный учёт.

## Создание целей в кабинете владельца

Код сайта не создаёт записи целей в личном кабинете. Если они уже есть, проверьте идентификаторы и не создавайте дубликаты.

1. Войдите в Яндекс Метрику под владельцем счётчика 114310945 и выберите этот счётчик.
2. Откройте «Цели» в левом меню → «Добавить цель».
3. Выберите «Целевое событие» (в старом интерфейсе — «JavaScript-событие»).
4. Укажите понятное название; условие — точное совпадение идентификатора. Введите один идентификатор из таблицы выше без пробелов.
5. Сохраните. Повторите для остальных отсутствующих целей.
6. В настройках счётчика проверьте, что выключены Вебвизор, карта кликов, аналитика/запись форм, электронная коммерция и автоматический сбор целей/событий. Не добавляйте автоматические цели отправки форм. Установка дополнительных тегов через Тег Менеджер отключена кодом сайта.
7. Откройте сайт с `?_ym_debug=2`, разрешите аналитику и выполните действие. Панель отладки → Events / Console должна показать номер 114310945 и идентификатор цели. Если панель не появилась, используйте `?_ym_debug=1` и консоль браузера.
8. Проверьте поступление данных в отчётах своего счётчика. Если включён фильтр «Не учитывать мои визиты», проверяйте в приватном окне. Без доступа к кабинету подтверждение статистики и состояния настроек счётчика невозможно.

## Фактическая браузерная проверка перед публикацией

В Chrome пройдены семь заданий Кристальной тропы до награды, включая неверный ответ и двойное нажатие. Официальный отладчик SDK показал все семь типов целей счётчика 114310945: четыре возраста, начало, задания и завершение. Проверены отказ, повторное открытие настроек и отзыв: после отзыва на следующей странице нет тега SDK, выбор возраста не добавляет Reach goal. Проверены переходы каталога и открытие всех пяти приключений, первая задача Башни, продолжение Библиотеки с четырьмя сохранёнными звёздами и сохранённая награда Сада с семью звёздами без нового события завершения. Ошибок приложения в консоли этих проверок не обнаружено; ошибок горизонтального переполнения на главной и в каталоге в проверенном настольном окне нет.

Не проводилось повторное ручное прохождение всех заданий остальных четырёх игр, проверка физических iPhone/iPad/Android и проверка отчётов в личном кабинете Метрики. Синтетические тесты ошибки SDK и хранилищ не являются тестом физического отключения сети на устройстве.
