# Озвучивание

Все файлы, которые воспроизводит браузер, находятся в `audio/`. Речь синтезирована голосом `ru-RU-SvetlanaNeural` с темпом −12%. В синтезатор короткие слоги передаются строчными буквами, чтобы их не читали как аббревиатуры. В игре они отображаются крупными печатными буквами. Реплики с несколькими допустимыми порядками слов подготовлены отдельно. Совпадающие реплики переиспользуют файлы из «Снежного королевства» с тем же голосом.

В `tools/build-phonemes.py` указаны границы выделенных фрагментов звуков. Пять гласных и три согласных выделены из новых реплик. Четыре записи согласных переиспользованы из «Снежного королевства». Файлы `phoneme-*.mp3` содержат отдельные звуки. Для них не используется браузерный синтез речи.

Зимние мотивы заменены новой мелодией из мягких колокольных тонов. Музыка приглушается при запуске речи, предыдущая реплика останавливается при выборе новой. `speech-manifest.json` хранит строки, пути и технические параметры файлов. Для повторной сборки используются Node.js, Python с `edge-tts` и FFmpeg.
